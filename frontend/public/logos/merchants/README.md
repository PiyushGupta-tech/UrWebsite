# Merchant logos (orchestration hero & partners)

Drop PNG or WebP files here using **kebab-case** slugs. The orchestration hero loads them automatically.

| File | Partner name |
|------|----------------|
| `bharat-cod.png` | Bharat COD |
| `green-web.jpeg` | Green Web Solutions |
| `groots.png` | Groots Pay |
| `paidkiya.png` | Paidkiya |
| `bingopay.png` | BingoPay |
| `aai-wallet.png` | AAI Wallet |

Add more by using the same pattern: `your-slug.png`, then add an entry in `MERCHANT_LOGOS` in `frontend/src/constants/logos.js`.

Recommended: transparent or white background, ~120×48px or similar aspect ratio.
